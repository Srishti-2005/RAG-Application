# FastAPI Contributor Guide & Project Overview

Welcome to the FastAPI open-source project repository! FastAPI is a modern, fast (high-performance), web framework for building APIs with Python 3.8+ based on standard Python type hints.

## Key Features
- **Fast**: Very high performance, on par with NodeJS and Go (thanks to Starlette and Pydantic).
- **Fast to code**: Increase speed to develop features by about 200% to 300%.
- **Fewer bugs**: Reduce about 40% of human (developer) induced errors.
- **Intuitive**: Great editor support. Completion everywhere. Less time debugging.
- **Easy**: Designed to be easy to use and learn. Less time reading docs.
- **Short**: Minimize code duplication. Multiple features from each parameter declaration.
- **Robust**: Get production-ready code with automatic interactive documentation.
- **Standards-based**: Based on (and fully compatible with) the open standards for APIs: OpenAPI and JSON Schema.

## Community & Getting Help
- **GitHub Discussions**: For general questions, architecture discussions, and beginner help, please open an issue in GitHub Discussions at `https://github.com/fastapi/fastapi/discussions`.
- **Discord Chat**: Join our community Discord server at `https://discord.gg/fastapi` to chat in real-time in the `#contributors` channel.
- **Twitter / X**: Follow `@fastapi` for release announcements.
